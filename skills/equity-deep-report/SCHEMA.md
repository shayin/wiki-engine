# 鱼头鱼身鱼尾 × 分批建仓节奏方法论（SCHEMA v2，2026-08-12）

> 个股深度报告第 ⑥c 节的标准方法论。每个报告必填：阶段定位 + 建仓节奏 + 卖出节奏。

## 一、阶段定位框架（鱼头/鱼身/鱼尾）

用 trend_template + ADX + RS(相对强度) 三维定位：

| 阶段 | trend_template | ADX | RS vs 大盘 | 价格位置 | 含义 |
|---|---|---|---|---|---|
| **鱼头**（启动/筑底） | <0.5 | <25 或刚转升 | 落后→走平 | 52周低点反弹<25% | 底部积累，趋势未确认 |
| **鱼身**（主升浪） | ≥0.875（Stage2）| ≥25 | 走平→领先 | 距52周高-15%以内 | 趋势确认，最大一段 |
| **鱼尾**（末端） | 从高位回落 | 从高位回落 | 领先→走平/回落 | 距52周高+15%以上/RSI持续>75 | 趋势衰竭，风险升 |

**过渡区**（鱼头末/鱼身前）：trend_template 0.5-0.875 + ADX 从<25向25靠近 + RS 开始转升 = 鱼身启动信号区。

## 二、分批建仓节奏（1/3 + 1/3 + 1/3 法则）

**核心原则：不一把梭，分 3 笔，每笔有明确触发条件。**

### 总仓位规划

先确定目标总仓位（基于 Murphy 2% 风险 + 因子权重 + 集中度约束），然后拆成 3 笔。

### 第 1 笔：左侧底仓（占总计划仓位 1/3）

| 项 | 内容 |
|---|---|
| **触发** | 价格进入价值中枢下方（安全边际≥10%）+ trend_template 在鱼头区（<0.5） |
| **位置** | 近 60 日低点 / MA50 / 前低支撑 |
| **性质** | 左侧试探——逻辑有但趋势未确认，用价格优势补偿不确定性 |
| **止损** | 支撑位下方 5-8%（破则认错，不扛） |
| **心态** | "可能继续跌，但这个价格值得试" |

### 第 2 笔：催化加仓（占总计划仓位 1/3）

| 项 | 内容 |
|---|---|
| **触发** | **第一个催化事件确认逻辑**（财报 beat / 政策落地 / 数据拐点 / 突破关键阻力） |
| **位置** | 催化后的回调（回踩支撑/回踩突破位），不在催化当天追 |
| **性质** | 半左半右——催化给了方向确定性，但还没形成完整趋势 |
| **止损** | 上移到第 1 笔的成本价（保本止损） |
| **心态** | "逻辑被验证了一部分，可以加" |

### 第 3 笔：趋势加仓（占总计划仓位 1/3）

| 项 | 内容 |
|---|---|
| **触发** | **趋势确认**：trend_template ≥0.875（Stage2）+ ADX ≥25 + 站稳 MA50/MA200 |
| **位置** | 趋势中的回调（回踩 MA10/MA20），不在突破当天追 |
| **性质** | 右侧——确定性最高，但价格也最高 |
| **止损** | trailing stop（MA13 或工具 trailing） |
| **心态** | "趋势确认了，加码骑鱼身" |

### 各阶段对应的建仓节奏

| 当前阶段 | 第 1 笔 | 第 2 笔 | 第 3 笔 | 操作 |
|---|---|---|---|---|
| **鱼头** | ✅ 现在就该挂限价单 | ⏳ 等催化 | ❌ 没趋势不加 | 在好价格挂 1/3 |
| **鱼头末/鱼身前** | ✅ 如果还没建 | ⏳ 催化临近 | ❌ 等趋势 | 补 1/3 + 准备催化加 |
| **鱼身** | — (已建) | ✅ 已加或加 | ✅ 趋势中可加 | 满 3/3 或 2/3 骑势 |
| **鱼尾** | ❌ | ❌ | ❌ | 不加，准备减 |

## 三、卖出节奏（分批减仓）

**同样不一把梭，分批减。**

| 减仓笔 | 触发 | 减多少 | 性质 |
|---|---|---|---|
| **第 1 笔减** | 到达乐观档价格区间 / RSI 持续>75 / trend_template 从高位回落 | 计划仓位的 1/3 | 鱼尾初：落袋一部分 |
| **第 2 笔减** | 跌破 MA13（短期趋势走弱） / 催化证伪（财报 miss） | 再减 1/3 | 鱼尾确认：降风险 |
| **清仓** | 跌破 MA50 / 跌破 trailing stop / 核心逻辑证伪 | 剩余全部 | 止损/逻辑变 |

**不减持仓（鱼身中）**：趋势完整（ADX≥25 + trend_template≥0.875 + 量价配合）= 让利润跑，不因为"涨多了"就减。

## 四、报告中的标准呈现格式（⑥c 节）

每个报告的 ⑥c 节必须包含以下子节：

```markdown
## ⑥c 趋势阶段 × 建仓节奏 ⭐

### 阶段定位
| 维度 | 值 | 判定 |
|---|---|---|
| trend_template | X.XX | 鱼头/鱼身/鱼尾 |
| ADX | XX.X | 强/弱趋势 |
| 距 52 周高/低 | -XX% / +XX% | 位置 |
| **当前阶段** | **鱼头末/鱼身中/鱼尾** | |

### 建仓节奏（目标总仓位：XX 股 / $XXXX）
| 批次 | 触发 | 价格区 | 仓位 | 状态 |
|---|---|---|---|---|
| 第 1 笔（左侧底仓）| 价值中枢下方+支撑区 | $XX-XX | 1/3 | ✅已建/⏳待触发 |
| 第 2 笔（催化加仓）| [具体催化事件]+回调 | 催化后 | 1/3 | ⏳等催化 |
| 第 3 笔（趋势加仓）| Stage2+ADX≥25+回调MA20 | 趋势中 | 1/3 | ❌未到 |

### 卖出节奏
| 批次 | 触发 | 减多少 | 状态 |
|---|---|---|---|
| 第 1 笔减 | 乐观档/RSI>75/模板回落 | 1/3 | ⏳ |
| 第 2 笔减 | 破MA13/催化证伪 | 1/3 | ⏳ |
| 清仓 | 破MA50/trailing stop/逻辑证伪 | 全部 | ⏳ |
```

## 五、关键原则

1. **永远分批，不一把梭**——无论买还是卖
2. **左侧只有第 1 笔**——后面必须有催化/趋势确认
3. **每笔有明确触发条件**——不凭感觉加仓
4. **止损跟着移动**——第 1 笔宽松（支撑下 5-8%），第 3 笔紧（trailing）
5. **阶段变了节奏就变**——鱼头不加第 3 笔，鱼尾不加任何笔
6. **"等"不是策略**——如果你判断是鱼头，就该挂第 1 笔限价单；如果判断是鱼尾，就该挂第 1 笔减仓单。不行动 = 没有策略
